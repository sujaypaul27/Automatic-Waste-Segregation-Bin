# Contributing to Automatic Waste Segregation Bin

Thank you for your interest in contributing to the **Automatic Waste Segregation Bin** project! Contributions from the open-source and maker community are warmly welcome.

## How Can You Contribute?

1. **Hardware Enhancements**: Suggesting or testing alternative sensors (capacitive proximity, optical spectroscopy, machine vision).
2. **Firmware Optimization**: Improving the non-blocking state machine, power-saving sleep modes, or telemetry reporting.
3. **Documentation**: Clarifying wiring instructions, adding 3D printing STL files, or improving interview walkthroughs.
4. **IoT Integrations**: Developing dashboards for Blynk, Home Assistant, Node-RED, or AWS IoT Core.

## Contribution Guidelines

1. **Fork the Repository**:
   Click the "Fork" button on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit Your Changes**:
   Write descriptive commit messages explaining *why* a change was made:
   ```bash
   git commit -m "feat(sensor): add support for capacitive proximity detection"
   ```
4. **Push & Open a Pull Request**:
   ```bash
   git push origin feature/your-feature-name
   ```
   Open a PR against the `main` branch with a clear description and testing results.
